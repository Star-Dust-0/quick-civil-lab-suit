# Quick Civil Lab Suite

A set of browser-based soil mechanics lab calculators for civil engineering work. Plain static HTML/CSS/JS - no build step.

Live: https://quick-civil-lab-suite.vercel.app/

## Tools

- **index.html** - home / hub page
- **atterberg.html** - Atterberg limits (LL/PL/PI)
- **proctor.html** - Proctor compaction test
- **sand_cone.html** - sand cone field density
- **sieve.html** - sieve analysis / grain size distribution
- **soil_class.html** - soil classification
- **stress_test.html** - stress calculations

## Deploying

Static site: deploy the repo root as-is (Vercel project `quick-civil-lab-suit`, framework "Other", no build command). `CNAME` points at `quick-civil-lab-suite.vercel.app`.
